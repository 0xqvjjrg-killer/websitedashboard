# DARKPANEL

Dashboard pelacak payload foto (.jpeg). Static site — jalan selamanya di GitHub Pages gratis.

- Tabel log hit: IP, lokasi, ISP, device, OS, battery %, charging, jaringan, layar, timezone, GPS presisi
- Builder payload: upload foto -> generate .jpeg berisi script pelacak
- Data disimpan permanen via GitHub Issues API (tidak akan hilang)
